# 六段提示词手册

进提示词的段落：identity → HEAD，camera/adapt → HEAD，allow/tail → TAIL。
forbid 不进模板，但必须写——它逼你把「不许出现什么」想清楚，也方便回看时定位。

## identity —— 只描述「这一个产品」
- 逐部件列，带数量与位置：`① 盘绕约 5 圈的钢缆（黑与深棕橙交织暗纹）② 黑色塑料锁头（蓝按钮、侧钥匙孔）③ 3 把银色钥匙 ④ 独立黑车架支架`。
- 带可数细节（几颗螺丝、几条筋、几个孔）：模型数不清就会自己加。
- 印字/logo 写清拼写、位置，并说「不是 X」（`空心圆角方形波浪边印章，不是皇冠`）。
- 不要评价性词（高级/时尚/精美）——模型会往它自己的审美跑。

## camera —— 场上的物体 → 朝向 → 贴合证据 → 遮挡 → 机位
```
① 车架管：深炭灰碳纤维圆柱（哑光细碳纹 + 一条细红装饰线），从画面左侧偏下进入向右上角延伸，与水平线约 30°。
② 朝向：壶架轴线（底托→壶口）与管轴完全平行，壶口朝右上、底托朝左下，斜卧在管子前侧，不是竖直站立。
③ 贴合：背板长边与管轴平行、整条压住管壁、没有透光缝；两颗沉头螺丝沿管轴一上一下穿过背板，与背板齐平。
④ 遮挡：壶架在管子前方；被压住那段管子看不见，只在壶口右上、底托左下各露出一小段，管子不许从镂空穿出。
⑤ 机位：相机在左前方约 35°、与产品齐平（不俯拍不仰拍），产品占画面约 75%。
```
- **软物穿扣**：`织带从扣子内孔一侧进另一侧出、内孔能直接看到布面；扣子金属脊压住织带；自然下垂不悬空`。
- **俯视展示**：肢体伸直铺开 + 「相机正上方垂直向下，严格俯视，不是平视不是斜拍」。
- **正面展示**：相机在被穿部位正前方、高 15° 俯角 + 「不是侧面机位、不是垂直俯拍」。
- **穿戴类**：先写人与背景的空间关系（人坐地上、顶部带膝盖、脚落地有投影），再写机位。

## adapt —— 只解决「主体会不会糊在背景里」
- 深色产品 → 亮背景 + 轮廓光，并写「保持纯黑，不许提亮成灰色」。
- 浅色产品 → 深一档台面 + 侧光压体积，并写「不许发黄、不许过曝」。
- 同色相撞（军绿鞋 + 黑旋钮）→ 明写「用轮廓光把旋钮边缘勾出来」。
- 背景换掉参考图的底色（防判同款）：直接指定材质与色温（浅灰微水泥 / 深灰石板 / 暖棕木地板）。

## allow / tail
- allow 宁少不多；任何可能被当道具的（鞋、包装、瓶子、手）都要显式列出或禁掉。
- tail 放最容易错的 1~3 条：数量、正反面、符号形状、颜色、印字拼写。

## 返工信号 → 改哪一段
| 现象 | 改哪里 |
|---|---|
| 产品被改款/加零件 | identity 补「共 N 个」，tail 再说一次 |
| 装不上/悬空/穿插 | camera ③④ 补贴合证据与遮挡句 |
| 机位不对（要正面给了侧面） | camera ⑤ 用否定句锚定 |
| 主体糊进背景 | adapt 加轮廓光 / 换背景明度 |
| 多了道具或文字 | allow 收紧，tail 重申「画面别处不许有文字」 |
| 两条腿悬浮、没有身体 | camera ① 补人/地面/投影/景深 |
| 画面多了手/手指/人头 | forbid 明写「手、手指、手臂、人头」；要手入镜就只在 allow 放「一只手」并限定区域 |
| 和参考图那款撞色 | forbid 原名色 + 指定新色 |
| 同批几张像一套 | 机位 + 背景材质/明度 + 留白比例，每 SKU 至少变一项 |
| 叠印像贴上去的 | 墨色 18 左右、糊 0.6~1px，别用纯黑；底图留出干净无字的带字面 |
